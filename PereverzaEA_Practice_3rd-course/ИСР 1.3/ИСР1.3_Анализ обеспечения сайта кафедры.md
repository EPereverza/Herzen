### **1. Фрагмент руководства системного программиста (ГОСТ 19.503-79)**

#### **1.1. Общие сведения**

Программное обеспечение сайта кафедры представляет собой совокупность взаимосвязанных компонентов, функционирующих под управлением системы управления контентом (CMS) Grav. Программа построена по модульному принципу, что обеспечивает гибкость настройки и расширения функциональности без изменения ядра системы.

#### **1.2. Составные части программы**

Программа логически разделена на следующие основные компоненты, размещенные в корневой директории `grav/` и поддиректории `grav/user/`:

| Имя компонента | Расположение | Назначение |
|:---------------|:--------------|:-----------|
| **Ядро Grav** | `grav/` | Основной исполняемый код CMS. Обеспечивает базовую функциональность: маршрутизацию, обработку запросов, работу с файловой системой, кеширование, шаблонизацию (Twig) и парсинг Markdown. Не подлежит модификации. |
| **Модуль конфигурации** | `grav/user/config/` | Хранит настройки сайта и системных расширений. Включает основной файл `system.yaml`, а также файлы конфигурации плагинов (`plugins/*.yaml`), тем (`themes/*.yaml`). |
| **Модуль контента** | `grav/user/pages/` | Содержит все страницы сайта. Структура директорий модуля полностью соответствует структуре разделов сайта. Каждая страница представлена папкой с файлом контента (например, `default.md`), написанным на языке Markdown. |
| **Модуль тем** | `grav/user/themes/ict` | Отвечает за визуальное представление (отображение) сайта. Тема `ict` содержит набор шаблонов (`.twig`), таблиц стилей (`.css`, `.scss`), JavaScript-сценариев и медиа-ресурсов (изображения, шрифты). |
| **Модуль плагинов** | `grav/user/plugins/` | Набор расширений, добавляющих специфическую функциональность. Каждый плагин является независимым подмодулем, но встречаются и зависимые плагины. |
| **Модуль данных** | `grav/user/data/` | Используется для хранения данных, генерируемых в процессе работы программы. Включает поддиректории для загруженных документов (`documents`), логов (`logerrors`), кеша фидов (`feed`), сообщений (`notifications`) и др. |
| **Модуль учетных записей** | `grav/user/accounts/` | Содержит YAML-файлы с данными пользователей системы. |

#### **1.3. Связи между составными частями**

**1. Обработка пользовательского запроса:**
   - HTTP-запрос поступает в **Ядро Grav** через файл `index.php`.
   - Ядро, используя **Модуль конфигурации**, определяет активную тему и загруженные плагины.
   - На основе URL запроса ядро находит соответствующую страницу в **Модуле контента**.
   - Ядро загружает контент страницы и передает управление **Модулю тем** для генерации HTML.

**2. Генерация страницы:**
   - Шаблоны из **Модуля тем** (`ict`) используют функции и фильтры, предоставляемые **Ядром Grav** и активными **Модулями плагинов**.
   - Плагины могут модифицировать данные перед отображением (например, плагин `shortcode-core` преобразует сокращения в HTML-код).
   - **Модуль данных** предоставляет динамическую информацию (например, список загруженных документов).

**3. Взаимодействие с администратором:**
   - Администратор авторизуется через плагин `login`, данные сверяются с **Модулем учетных записей**.
   - Административный интерфейс предоставляется плагином `admin`, который взаимодействует со всеми модулями для настройки и редактирования контента.

#### **1.4. Связи с другими программами**

1.  **Веб-сервер (Apache / Nginx):** Обеспечивает среду выполнения для PHP-кода и обработку статических файлов. Является точкой входа для всех HTTP-запросов.
2.  **Интерпретатор PHP:** Необходим для исполнения кода ядра Grav, плагинов и тем.
3.  **SMTP-сервер (опционально):** Используется плагином `email` для отправки писем (уведомления из форм обратной связи).
4.  **LDAP-сервер (опционально):** Может использоваться плагином `core-service-manager` для аутентификации пользователей через корпоративный каталог.

### **2. Список используемого программного обеспечения и технологий**

#### **Базовое ПО**

|Наименование|Назначение|
|---|---|
|Веб-сервер (Apache/Nginx)|Обработка HTTP-запросов, выполнение PHP-сценариев, обслуживание статических файлов.|
|PHP (7.4 / 8.0+)|Язык программирования, на котором написана CMS Grav и все ее компоненты.|


#### **CMS (Ядро)**

|Наименование|Назначение|
|---|---|
|Grav CMS|Основная система управления контентом, обеспечивающая организацию файлов, маршрутизацию и базовую логику сайта.|


#### **Плагины (ключевые)**

|Наименование|Назначение|
|---|---|
|Admin|Предоставляет графический интерфейс для управления сайтом (страницы, настройки, пользователи).|
|Form|Создание и обработка веб-форм (обратная связь, загрузка документов).|
|Login|Регистрация, аутентификация и управление доступом пользователей.|
|Email|Отправка email-сообщений (уведомления, подтверждения из форм).|
|Error|Кастомная обработка HTTP-ошибок (404, 403).|
|Problems|Диагностика проблем с установкой и окружением Grav.|
|Shortcode Core|Обработка сокращенного кода (shortcodes) для вставки сложных элементов прямо в тексте Markdown.|
|Page Inject|Встраивание содержимого одной страницы внутрь другой.|
|Breadcrumbs|Отображение навигационной цепочки ("хлебные крошки").|
|Archives / Feed / Pagination / Simplesearch|Формирование списков материалов, RSS-лент, постраничная навигация, поиск по сайту.|
|Events|Управление и отображение событий/календаря.|
|MathJax / Highlight / QRCode / YouTube|Отображение математических формул, подсветка кода, генерация QR-кодов, вставка видео.|
|Admin Power Tools / Admin Addon User Manager|Расширение функциональности административной панели.|
|Data Manager / Flex Objects|Инструменты для управления структурированными данными.|


#### **Тема оформления**

|Наименование|Назначение|
|---|---|
|ICT (кастомная тема)|Определяет визуальный дизайн, верстку и оформление всех страниц сайта. Содержит шаблоны Twig, CSS/SCSS стили и JavaScript.|


#### **Вспомогательные технологии**

|Наименование|Назначение|
|---|---|
|Markdown|Язык разметки для написания контента страниц.|
|Twig|Шаблонизатор для отделения логики от представления.|
|YAML|Формат файлов конфигурации.|
|SCSS|Препроцессор CSS для удобной разработки стилей.|
|JavaScript / jQuery|Обеспечение интерактивности на страницах.|
|Bootstrap / Unify|CSS-фреймворки, на которых базируется тема `ict`.|
|Composer|Менеджер зависимостей для PHP (используется для подключения сторонних библиотек).|
